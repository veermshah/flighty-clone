# Flighty Clone

A dark, mobile-first Flighty-inspired flight tracker built with Expo Router and TypeScript.

## Screenshots

Screenshots coming soon.

## Run

```bash
npm install
npx expo start
```

## Features

- Live, upcoming, and past flight tracking
- Interactive route map, progress, timeline, and aircraft details
- Flight search by number or route
- Friends and Passport summaries
- Persistent mock flight data with live status updates

Mock data only. Not affiliated with Flighty or any airline.
